# Microsoft Project Professional 2024

> Organize project schedules, coordinate resources, monitor milestones, and track delivery against an established plan.

Microsoft Project Professional 2024 is desktop project management software for building schedules, connecting tasks, assigning resources, and monitoring project progress. It provides tools for planning complex work, managing timelines, reviewing costs, and communicating project status.

The application combines Gantt charts, dependency-based scheduling, resource management, baselines, timelines, and reporting tools for structured project planning.

## Task Management

Tasks provide the structure for organizing project activities and deliverables.

| Feature | Purpose |
|---|---|
| Summary tasks | Group related activities into larger phases |
| Subtasks | Break work into smaller, manageable activities |
| Duration estimates | Record the expected time needed for tasks |
| Milestones | Mark important events and delivery points |
| Deadlines | Identify target completion dates |
| Task links | Establish relationships between dependent activities |

A structured task hierarchy makes project scope easier to review and helps teams understand how individual activities contribute to a larger deliverable.

---

## Gantt Charts and Scheduling

The Gantt Chart view combines task information with a timeline, helping users understand the sequence and duration of project activities.

| Scheduling Tool | Description |
|---|---|
| Gantt bars | Display task durations on a timeline |
| Dependency links | Show relationships between connected tasks |
| Critical path | Identify activities that influence the planned completion date |
| Baselines | Preserve a reference plan for performance comparisons |
| Multiple timelines | Present selected project activities across timeline views |
| Automatic scheduling | Calculate dates based on task relationships and scheduling settings |

Project schedules should be reviewed when dependencies, working calendars, or task durations change.

---

## Resource Management

Resource management helps coordinate assignments and identify potential workload conflicts.

| Feature | Description |
|---|---|
| Resource assignments | Connect resources with specific tasks |
| Work allocation | Define the work expected for each assignment |
| Resource availability | Represent available working time |
| Resource leveling | Adjust certain assignments to address overallocations |
| Resource costs | Associate rates and costs with planned work |

Resource leveling can change task dates. Review the resulting schedule to ensure that important deadlines and project constraints remain appropriate.

## Project Costs and Baselines

Project Professional supports project performance reviews by comparing the current schedule and recorded information with an established plan.

| Tool | Use |
|---|---|
| Cost estimates | Record expected costs for project work |
| Resource costs | Calculate costs associated with assigned resources |
| Baseline comparison | Review differences between planned and current progress |
| Schedule variance | Identify differences between planned and actual dates |
| Cost reporting | Summarize available financial information |

The accuracy of project reports depends on consistent estimates, updated task information, and reliable cost records.
